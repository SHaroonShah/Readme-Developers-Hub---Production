Complete the following Test Pack requirements:

1. **Create Labels**

   Provide at least 3 test labels created in SAPIENT using your Sandbox Shipping Account. The labels must have different destination details and different weights and must use the service you are testing.

   * Freight 2 Post customers only: Include the customs documentation generated by SAPIENT, either a combined shipping label + CN22 or a shipping label with a separate CN23. See [Combined label + CN22](https://docs.intersoftsapient.net/docs/combined-label) for more information.
2. **Produce Manifest / Sales Order Summary**

   * **Commercial Clearance customers only:** Manifest the test shipments using the [Manifest Shipments API.](https://docs.intersoftsapient.net/reference/post_v4-manifests-carriercode) Include the Royal Mail Sales Order Summary in your Test Pack.
3. **Gather Request and Response Examples**

   Provide an example of an API request and response for each of the following:

   * Create Shipment
   * Update Status to Cancel
   * Manifest Shipments
   * **Freight 2 Post customers only:** Include API request and response examples for the required International Arrivals Containers (A-Scan) API calls.
4. **Print Test Labels**

   Print the test labels using your production printer. Include an image or scan of the printed labels with your Test Pack for initial approval.
5. **Submit the completed Test Pack** to [onboarding@intersoft.co.uk](mailto:onboarding@intersoft.co.uk).
