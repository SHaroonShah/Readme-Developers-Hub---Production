In SAPIENT, you can edit the <Glossary>shipping location</Glossary> to enhance customer service by providing the latest contact and operational details relevant to shipping activities.

## Overview

<Cards columns={2}>
  <Card title="Why Edit Shipping Locations?" icon="edit">
    Keep shipping information current and accurate to ensure smooth operations and minimize delivery errors.
  </Card>
  <Card title="Quick Access" icon="map-marker-alt">
    Navigate to **Shipping Locations** in the left panel to manage all your shipping destinations.
  </Card>
</Cards>

## Step-by-Step Process

<Accordion title="Step 1: Access Shipping Locations" icon="navigation">

In the left navigation panel, select **Shipping Locations**.

<Image alt="Accessing shipping locations" align="center" border={true} src="https://files.readme.io/a84f50bafad4110e2244fa56d73b34787cf197d6a4e3de326ad287880d85e835-Shipping_locations_option.png">
  Accessing shipping locations
</Image>

</Accordion>

<Accordion title="Step 2: Select Location to Edit" icon="cursor-pointer">

On the **Shipping Locations** page that appears, select the shipping location that you want to edit and on the **View Shipping Location[location name]** form that opens, select the edit button ![alt text](https://files.readme.io/75c6ec5f5e8f7df63e70c61fec2bcf905b75de1822a4edbbd3d25ef5bd51b5ee-Edit_shippig_location_button.png).

<Image alt="Selecting option to add shipping location" align="center" border={true} src="https://files.readme.io/0ffbf35c04a6aa2b82329f91bca4df861fae2511cfbe07feeee4d9e97827d8c5-Edit_shippig_location_option.png">
  Selecting option to edit shipping location
</Image>

</Accordion>

<Accordion title="Step 3: Update Location Information" icon="edit">

On the **Edit Shipping Location[location name]** form that opens, update the necessary information as explained in the [Add shipping location](https://docs.intersoftsapient.net/docs/add-a-shipping-location) section.

<Image alt="Entering location details" align="center" border={true} src="https://files.readme.io/9cf3fcac3d841d769ecdc90e1f086dddda4bc04efcdc34618ad5f341309206bb-Editing_shipping_location.png">
  Editing shipping location
</Image>

</Accordion>

<Accordion title="Step 4: Save Changes" icon="save">

After entering all the relevant information, select the Save Changes button ![alt text](https://files.readme.io/5219ced5f0c085839c06983551f8930bbcb2c08eb4da69a39e36d59f4a5727c7-Save_changes_button.png).

Once done, the shipping location is updated successfully.

</Accordion>
