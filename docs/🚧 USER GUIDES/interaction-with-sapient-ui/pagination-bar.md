Some tables in SAPIENT may have more content than can be displayed on one page. Use the pagination bar at the bottom of the contents panel to view more of the current table items.

<Image alt="Pagination bar" align="center" border={true} src="https://files.readme.io/22ae167a5c65b3b4feed20f0922d1a08b0eaca9c647ac0b74eb2b9ef89debe35-Pagination_bar.png">
  Pagination bar
</Image>

## Navigation Controls

<Cards columns={2}>
  <Card title="Previous Page" icon="chevron-left">
    Navigate backward through your table data using the previous page button.
  </Card>
  <Card title="Next Page" icon="chevron-right">
    Move forward through your table data using the next page button.
  </Card>
  <Card title="Direct Page Access" icon="list-ol">
    Jump directly to any specific page number in your table.
  </Card>
  <Card title="Item Counter" icon="calculator">
    View the current items displayed and total count in your table.
  </Card>
</Cards>

## Pro Tips

<Accordion title="Optimization Tips" icon="lightbulb">

### Entries Per Page

You can also limit the number of entities in the table by selecting the entities from the **entries per page** ![alt text](https://files.readme.io/9d9c6f5d79965d90b05c5d1826fb9c162f6733773a1962135047bb0c633710aa-Prev_button.png) dropdown.

This feature helps you:
- Control the amount of data displayed at once
- Improve page loading performance
- Customize your viewing experience based on your needs

</Accordion>
