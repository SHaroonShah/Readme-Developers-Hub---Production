**Shipping Location**

- The physical locations that you send shipments from. A shipping location must have a name/alias and an address. Every Shipping Location has a global unique identifier assigned by Sapient. Either Shipping Location Alias or the global identifier can be used in API calls where you need to send ShippingLocationId

**Default Shipping Location **

- A customer can have one default shipping location at any given time. Any of your Shipping Locations can be set as the default shipping location. The default shipping location for the customer cannot be deleted.
