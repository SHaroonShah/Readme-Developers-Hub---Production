**DPI** (Dots Per Inch)

* A measure of spatial printing defined by the number of dots that can be printed in a line with the span of 1 inch.

**ISO Country Code**

* The International Standard for country codes and codes for their subdivisions. Using codes saves time and avoids errors as instead of using a country’s name (which will change depending on the language being used), we can use a combination of letters and/or numbers that are understood all over the world. Postal organizations throughout the world exchange international mail in containers identified with the relevant country code. [https://www.iso.org/iso-3166-country-codes.html](https://www.iso.org/iso-3166-country-codes.html)
