The contents panel is a central part of the user interface that displays the content of the currently selected tab, option, or item.


<Image src="https://files.readme.io/368df6f180bee1d3a95fc9bc9d71b3df7583b2262d40ca7383eecd614596b2df-Contents_panel.png" alt="SAPIENT contents panel" align="center" caption="SAPIENT contents panel" />


## Main components

Depending on the feature selected, it may accommodate different elements, the main of which are:

<Cards>
  <Card title="Table" href="https://docs.intersoftsapient.net/docs/table" icon="fa-solid fa-table" target="_blank">
    The primary data display component that organizes and presents information in rows and columns for easy viewing and interaction.
  </Card>

  <Card title="Pagination Bar" href="https://docs.intersoftsapient.net/docs/pagination-bar" icon="fa-solid fa-chevron-left" target="_blank">
    Navigation controls that allow users to browse through multiple pages of content when dealing with large datasets.
  </Card>

  <Card title="Search and Filter Bar" href="https://docs.intersoftsapient.net/docs/search-and-filter-panel" icon="fa-duotone fa-filter" target="_blank">
    Interactive tools that enable users to quickly find specific content and apply filters to refine their data view.
  </Card>
</Cards>
