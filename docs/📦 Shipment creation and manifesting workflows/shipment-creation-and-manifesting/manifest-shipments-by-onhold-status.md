If you sell pre-ordered goods that will be available to ship in the future, you can create the shipments as normal and put them on hold for up to 28 days. 

When the goods become available you can manifest the shipments without having to change the status again, manifesting by status “**OnHold**”.

Be aware that all shipments that you have put on hold will be manifested. If you don’t want to manifest all shipments that are on hold you will need to release the shipments you want to manifest.

If you create the shipments using Action: Create or Allocate, labels must be printed before you can update the shipments status to "**Hold**”. 

> 🚧 Shipments that have been on hold for more than 28 days will be cancelled automatically.
