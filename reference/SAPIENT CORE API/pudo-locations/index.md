---
title: PUDO Locations
excerpt: >-
  PUDO (Pick Up Drop Off) allows a location to be specified for the recipient to
  pick up/collect a shipment from (in the case of an outbound shipment) or the
  sender to drop the shipment off to (in the case of a return shipment). The
  PUDO location is likely to be a Post Office, local shop, retail outlet etc.
