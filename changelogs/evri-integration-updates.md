Following Brexit, the UK and the EU reached an agreement known as the Northern Ireland Protocol to facilitate trade between mainland Great Britain and Northern Ireland. Now, the Windsor Framework has replaced the Northern Ireland Protocol.  As part of this change, you can create a shipment request using any EVRi service only for the following models:

* B2C
* D2C
* C2B
